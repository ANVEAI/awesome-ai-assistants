# Contributing to Awesome AI Assistants

Thank you for your interest in contributing! 🎉

## Guidelines

### Adding a New Resource

1. Make sure the resource is related to AI assistants or autonomous agents
2. Check that it's not already in the list
3. Add it to the appropriate section in alphabetical order
4. Use the following format:

```markdown
| [Name](URL) | Description | Additional Info |
```

### Quality Standards

- The resource should be actively maintained
- It should have clear documentation
- Commercial products should have a free tier or trial
- Open source projects should have a reasonable number of stars (>100)

### Pull Request Process

1. Fork the repository
2. Create a new branch (`git checkout -b add-new-resource`)
3. Make your changes
4. Commit with a clear message (`git commit -m "Add [Resource Name]"`)
5. Push to your fork (`git push origin add-new-resource`)
6. Open a Pull Request

### What We're Looking For

- ✅ AI assistants and chatbots
- ✅ Autonomous agent frameworks
- ✅ LLM application tools
- ✅ Tutorials and learning resources
- ✅ Messaging platform integrations

### What We're NOT Looking For

- ❌ General machine learning tools (unless AI assistant focused)
- ❌ Abandoned projects (no updates in 1+ year)
- ❌ Resources behind paywalls without free options
- ❌ Duplicate entries

## Code of Conduct

Be respectful and constructive in all interactions.

## Questions?

Open an issue if you have any questions!
